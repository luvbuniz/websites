# Alejo Painting Inc. website

A polished, mobile-friendly static website for Alejo Painting Inc. in Sarasota, Florida.

## Included

- Responsive one-page design
- Updated Alejo wordmark using the existing blue, red, and yellow brand colors
- Painting services and project gallery
- New cleaned cabinet-preparation photo
- Click-to-call and click-to-text quote actions
- Business email placed in the footer
- Accessible navigation and reduced-motion support
- Local business structured data for search engines

## Publishing

The site is designed to publish directly from the repository root with GitHub Pages. It has no build step and no third-party front-end dependencies.
